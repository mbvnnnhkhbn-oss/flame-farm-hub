# 🔥 CoinFlames

Telegram Mini App — earn coins by watching ads, completing tasks, mining, referrals, and daily check-ins.

## Tech Stack

- **Framework:** TanStack Start v1 + React 19
- **Styling:** Tailwind CSS v4
- **Backend:** Lovable Cloud (Supabase Postgres)
- **Auth:** Telegram WebApp HMAC-SHA256
- **Ads:** AdsGram AI
- **Hosting:** Vercel (see deploy guide)

## Quick Start

```bash
bun install
bun run dev
```
